# Ask a Massachusetts court for a change if you have a disability

Use this interview to ask for a change that helps you take part in a Massachusetts Trial Court case. It fills out the court's request form for you to sign and bring or mail to the court.

Run the interview at `docassemble.AdaInterview:data/questions/ada_interview.yml`.

The source is the [Massachusetts Trial Court's September 29, 2026 revision](https://www.mass.gov/doc/massachusetts-trial-court-request-form-for-an-accommodation-under-the-americans-with-disabilities-act-tc0035/download). The package template preserves the court's two-page form and PDF tags. Its field names are adapted for Docassemble, and its XFA data and legacy JavaScript actions have been removed.

Original interview by Jessica Vandervort.
